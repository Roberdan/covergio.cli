# Product Overview

## Convergio CLI (formerly Gemini CLI)

Universal AI Agent Orchestration Platform - A command-line AI workflow tool that connects to your tools, understands your code, and accelerates your workflows.

### Core Capabilities

- **Large Codebase Analysis**: Query and edit codebases within and beyond Gemini's 1M token context window
- **Multimodal Generation**: Generate new apps from PDFs or sketches using Gemini's multimodal capabilities  
- **Workflow Automation**: Automate operational tasks like querying pull requests or handling complex rebases
- **Tool Integration**: Connect new capabilities via tools and MCP servers, including media generation
- **Grounded Search**: Built-in Google Search tool for grounding queries

### Universal Agent System

Advanced multi-agent orchestration framework featuring:
- **Agent Factory**: Dynamically creates domain-specific agents
- **Specialized Agents**: Customer Service, Data Analysis, Creative Assistant, Technical Support
- **Task-Master-AI Integration**: Intelligent task breakdown and agent assignment
- **Personality System**: Optimized agent personalities for specific domains

### Target Users

Developers, DevOps engineers, and technical teams looking to accelerate their workflows through AI-powered automation and code assistance.
