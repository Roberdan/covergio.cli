# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records for the Convergio CLI project.

## Format

Each ADR follows the format below and is numbered sequentially (e.g., `0001-decision-title.md`).

```markdown
# ADR NNNN: Title

- **Status**: Proposed | Accepted | Deprecated | Superseded
- **Date**: YYYY-MM-DD
- **Authors**: @github-handle

## Context

What is the issue or decision that needs to be made?

## Decision

What is the change that we're proposing and/or doing?

## Consequences

What becomes easier or harder as a result of this decision?
```
